大信防水成本控制 V18｜真正工地離線正式版

這是正式可用版，包含：
- PWA 可安裝到 Android / iPhone 主畫面
- 第一次連網後，可在工地離線使用
- 98 項單價與單位自動帶入
- 員工工資、歷史紀錄、LINE 回報
- 離線/連線狀態提示
- 完整備份 / 匯入備份

部署更新方式：
1. 將本資料夾內檔案上傳到 GitHub 專案根目錄
2. Commit changes
3. 等待 Vercel 自動部署
4. 用手機開啟 https://dashin-waterproof-report.vercel.app
5. Android：Chrome → 安裝應用程式
6. iPhone：Safari → 分享 → 加入主畫面
