大信防水成本控制 V18｜真正工地離線正式版

這是正式版，可直接提供工地人員安裝使用：
1. 第一次連網安裝後，可在沒有網路時重新開啟 App。
2. 頁面右上角顯示「已連線 / 離線模式」。
3. 98項單價、單位自動帶入、工資、計算、歷史紀錄均在本機運作。
4. 新增「匯出完整備份 / 匯入備份」。
5. 備份包含 dashin_settings 與 dashin_reports。

測試方式：
A. 將本資料夾 5 個網站檔案上傳至 GitHub 專案根目錄。
B. 等待 Vercel 部署完成。
C. 手機先連網開啟網站一次並安裝 PWA。
D. 關閉 App。
E. 手機開啟飛航模式 / 關閉 Wi-Fi 與行動網路。
F. 再從主畫面打開「大信防水成本控制」。
G. 若能正常進入並新增/查詢資料，即代表離線快取成功。

注意：
- 第一次安裝一定需要網路。
- LINE 實際傳送仍需要網路；但 LINE 回報文字預覽與複製可離線使用。
- 不要清除瀏覽器網站資料，否則 localStorage 與離線快取可能會被移除。
